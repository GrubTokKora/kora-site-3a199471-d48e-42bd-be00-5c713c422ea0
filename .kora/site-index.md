## support files
Files that are not pages. A line marked [content] holds words or data a visitor reads, so a
change to the site's content can land there; the rest only make the site work or look right.
- `site.js` — sticky-header shadow and closing the mobile menu
- `llms.txt` — plain-text summary of the practice for AI answer engines  [content]
- `robots.txt` — crawler rules and the sitemap link
- `sitemap.xml` — every indexable page
- `DESIGN.md` — the design decision the site was built from
